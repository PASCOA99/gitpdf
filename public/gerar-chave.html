Gerar chave de segurança

Este utilitário gera a chave SESSION_KEY usada para proteger a sessão no serviço da Cloudflare. Ela é criada localmente no navegador, sem transmissão para nenhum servidor.

Copie a chave para Cloudflare → Worker → Settings → Variables and Secrets, com o nome SESSION_KEY, tipo Secret. Não publique a chave no GitHub.
